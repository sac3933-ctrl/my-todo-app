# 📌 라이트 스펙

## 1. 화면 목록 (3개 이내)

| 화면명                 | 목적             | 핵심 요소               |
| ------------------- | -------------- | ------------------- |
| 메인 화면               | 할 일 즉시 추가 및 관리 | 입력창, 할 일 리스트, 완료 체크 |
| 간편 입력 레이어 (팝업/하단시트) | 3초 내 빠른 등록     | 단일 입력 필드, 등록 버튼     |
| 설정 (옵션)             | 최소 사용자 설정      | 초기화, 간단 옵션          |

---

## 2. 데이터 구조 (간단 JSON)

```json
{
  "todos": [
    {
      "id": "uuid",
      "text": "회의자료 작성",
      "isCompleted": false,
      "createdAt": "2026-05-01T09:00:00"
    }
  ]
}
```

---

## 3. 사용자 흐름 (3~5단계)

| 단계 | 사용자 행동 | 시스템 반응      |
| -- | ------ | ----------- |
| 1  | 앱 실행   | 메인 화면 즉시 노출 |
| 2  | 할 일 입력 | 입력 상태 활성화   |
| 3  | 등록     | 리스트 최상단 추가  |
| 4  | 완료 체크  | 상태 변경       |
| 5  | 삭제     | 리스트 제거      |

---

## 4. 화면별 주요 동작

### 📱 메인 화면

* 할 일 추가: Enter 또는 버튼으로 등록
* 완료 표시: 체크 시 상태 변경
* 삭제: 스와이프 또는 버튼
* 목록 조회: 최신순 정렬

### ⚡ 간편 입력 레이어

* 빠른 입력 (FAB 호출)
* 입력 후 자동 저장

### ⚙ 설정

* 전체 데이터 초기화
* 알림 등 최소 옵션
